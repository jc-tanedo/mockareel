# Mockareel Android preview

[Download the APK](https://github.com/jc-tanedo/mockareel/raw/refs/heads/apk-preview/mockareel-preview.apk)

Development build from source commit `3371a846ee6c982e5dd21a81a765a7e1726dc671`.
Requires Android 7.0 or newer. Android may ask you to allow installation from your browser.

This preview includes the place editor, media selection, timing controls, and local project saving. MP4 export is not implemented yet. Live Google Places search requires a build configured with a Maps API key; this build supports manual place editing.
