# Mockareel 0.13.0

Create Maps reels without setting up a Google API key, and use animated GIFs with the same timing controls as your other media.

## What's new

- **Key-free Maps lookup:** search by place name/city or paste a Google Maps share link. Select a result, import available details and an optional featured review, then edit the fields normally.
- **Key-free map headers:** choose **Place → Header → Load Google map**, pan/zoom in the framing screen and save the map with your project. Keep the place below the guide line to leave it visible after the intro. Original Google branding and attribution are retained.
- **Optional API access:** enter a personal key under **Advanced · Google Maps**. The settings list **Places API (New)** for API lookup and **Maps Static API** for API headers, with billing required for API requests. Browser mode remains the default. This release contains no shared Maps key.
- **Animated GIFs:** select a duration/start offset and toggle **Loop GIF**. Preview and export reuse a cached video of the selected segment. Existing GIF photos are detected automatically, including files with misleading extensions. Original GIF files and editable timing stay in projects and backups.

## Fixes

- Maps and FYP previews preload incoming players and retain outgoing players during slides, avoiding decoder restart flashes.
- Preview playback stays paused on the final frame. Delayed native playback commands can no longer override the end-of-reel pause.
- Map headers use one continuous image during the intro, removing the duplicated footer strip.
- GIF media no longer reaches the video encoder as unsupported `image/gif` input.

## Install and project migration

Download `mockareel-0.13.0-release.apk` below. This is the normal **Mockareel** app (`dev.mockareel.mockareel`), signed with the existing production release key, and updates production 0.12.2 installations.

**Mockareel Maps POC is a separate app.** To move its projects, open a project in the POC app, select **Share project backup**, then import the `.mockareel` file from Mockareel's project library. Keep the POC app until your projects have been transferred. Personal API keys are not included in backups.

Browser map capture requires Android 8 or newer; uploaded/photo headers and optional API headers remain alternatives. Google page layouts and available fields can vary. GIF animation uses the 30 fps output clock; transparency is flattened against black in the prepared video. See the [Maps](https://github.com/jc-tanedo/mockareel/blob/main/docs/google-maps.md) and [GIF](https://github.com/jc-tanedo/mockareel/blob/main/docs/gifs.md) guides.

Validation: 85 Flutter tests, six Kotlin tests and five release-metadata tests, plus formatting and Dart analysis. Device testing confirmed Maps lookup/capture, GIF export and the preview fixes. The release workflow verifies the signed APK's package/version, ZIP integrity, 16 KB alignment and credential-pattern scan before publishing it with its SHA-256 checksum.
