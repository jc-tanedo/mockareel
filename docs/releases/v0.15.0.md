# Mockareel 0.15.0

A Material Design 3 redesign with clearer editing workflows, selectable color
schemes and more reliable Streetview transitions and Android exports.

## What's new

- **Redesigned workspace:** updated project library, template picker, editor cards,
  clip strip, responsive inspector panels, text/audio controls and export monitor.
- **Editor color schemes:** choose Electric Mint, Sunset Ember, Ocean Breeze,
  Cyber Violet or Solar Flare in Settings. The choice persists on the device and
  is independent of each project's output Light/Dark setting.
- **Story controls:** choose individual decorative story buttons in Maps output.
- **Streetview polish:** directional transitions, turntable direction controls and
  the full-screen-to-thumbnail return-to-Maps zoom-out in exported videos.
- **Background export on Android:** a foreground service covers preparation and
  encoding, with progress and completion notifications. Allow the notification
  prompt to see progress while using another app or locking the screen.

## Fixes and improvements

- Live media players persist through Streetview map thumbnails and media handoffs.
  Held end frames no longer reset when returning to the ending map.
- Prepared posters render without an intermediate loading placeholder. Streetview
  scenes decode required assets before capture so cache eviction cannot introduce
  empty transition frames.
- Export capture continues when regular display frames stop in the background.
  Completion, cancellation and errors release the foreground service and wake lock.
- Google Maps lookup uses newly saved API settings immediately, and automatic map
  headers load after importing a place.
- Media inspection and music selection handle more MP4/AAC container variants.
- Older signed turntable angles migrate to the angle/direction controls without
  losing their rotation. Legacy story-control choices remain supported.
- Build setup actions use SHA-pinned Node 24 releases, removing the Node 20 and
  setup-java v4 deprecation annotations.

## Install and existing projects

The signed release APK updates **Mockareel** (`dev.mockareel.mockareel`) and uses
Android build number **24**. **Mockareel Debug** remains a separate app. Transfer
projects between them with **Share project backup** and import the `.mockareel`
files in the target app. Existing project and backup formats remain supported.

Background export is active while the job runs; force-stopping the app or OS
process termination can interrupt it, and interrupted jobs do not automatically
resume. If notifications were denied, enable them in Android settings to display
export progress. Source video audio remains muted; select background music for
reel audio. Streetview uses ordinary media, not interactive 360° panoramas.

## Validation

Release preparation covers formatting, Dart analysis, 131 Flutter tests, native
Android compilation/unit tests and 21 CI helper tests. Export tests check captured
media pixels, cache eviction, thumbnail zoom-out geometry and background frame
capture. The latest debug APK received a device smoke check before release prep.
Hardware-specific codec and background behavior still require device testing.
