# Mockareel 0.16.0

**Streetview 3D** turns a set of locations and ordinary phone photos into a
vertical journey. Start on a 2D map, fly into the scene, then move the camera
between locations.

- Choose locations first and assign photos, videos or GIFs to each one. When
  importing clips without an assigned location, the editor uses embedded GPS
  coordinates where available and otherwise inherits the preceding clip’s pin.
- Capture buildings and terrain from open data, including PLATEAU and Overture
  where available. You can try Tokyo Station with the included offline scene.
  With your own Google Maps Tiles API key, the editor first tries a Google
  Photorealistic 3D Tiles capture.
- Mount media on a visible building wall and shuffle through other suitable
  walls. When a capture has no suitable wall, the media appears at the pin.
  Geometry detail and building colors depend on local coverage.
- Choose a slow step left, step right or walk forward through a still photo.
  The first use downloads a depth model. Android prepares the walkthrough on
  the device, and portable backups include the prepared photo and map assets.

Install the signed release APK to update **Mockareel** to Android build **25**.
To transfer a project from **Mockareel Debug**, use **Share project backup**
and import the resulting file into **Mockareel**.
