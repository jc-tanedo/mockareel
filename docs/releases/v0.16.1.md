# Mockareel 0.16.1

Streetview 3D can now recover missing pin coordinates automatically. Reopen a
saved journey to look up its missing pins and fetch geometry for the locations
that resolve. The editor saves the coordinates with each location and its
linked clips.

The Maps picker reads coordinate links and Plus Codes from the selected
listing. If a 3D location still needs a pin, Android looks up its name and
address. When the result is ambiguous or the lookup is offline, you can use
**Retry pin lookup** or **Enter pin coordinates**.

Install the signed APK to update Mockareel to Android build **26**.
