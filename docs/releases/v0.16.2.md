# Mockareel 0.16.2

The Maps picker now reads visible search results while the page is still
loading. If the selected listing’s details time out, you can still use the
place from its search card.

Pin lookup now preserves coordinates in Maps links with unreadable tracking
parameters and recognizes more abbreviated Plus Codes. If a place-name search
times out, the picker tries Android location search. You can also choose
**Use Android location search** from the search menu and select the matching
address yourself.

Install the signed APK to update Mockareel to Android build **27**.
