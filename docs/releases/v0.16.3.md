# Mockareel 0.16.3

The Maps picker now shows latitude and longitude before you tap **Use this
place**. Pin lookup recognizes spacing differences in place names, including
“Yomiuri Land” and “Yomiuriland.”

If Android cannot identify the pin, Mockareel can use a landmark’s coordinates
from English Wikipedia after matching its name, locality and website. Reopen a
saved Streetview 3D journey to retry any missing pins.

Install the signed APK to update Mockareel to Android build **28**.
