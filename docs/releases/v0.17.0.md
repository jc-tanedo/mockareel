# Mockareel 0.17.0

Material 3 Expressive motion across the editor and templates, 60 fps exports,
and smoother same-pin transitions in Streetview 3D.

## What's new

- **Material 3 Expressive motion & 60 fps export parity:** shared analytical
  spatial/effects springs (`M3Motion`) and a unified 60 fps clock synchronize
  live previews and rendered MP4/GIF exports across Maps, Streetview,
  Streetview 3D, and Feed templates.
- **Streetview & Maps polish:** smooth thumbnail-to-fullscreen cutout expand and
  close-button shrink-to-map transitions, `slowSpatial` place-sheet reveal,
  morphing pagination dots, and an M3 wavy export progress indicator shared
  between previews and the editor monitor.
- **TikTok FYP Feed transitions:** responsive app launch/close ripples across
  all home OS presets, animated keyboard dismiss, and a shared-axis handoff from
  Search straight into live scaling Post 0 playback.
- **Streetview 3D same-pin wall upgrades:**
  - Enforces distinct building walls for clips sharing a pin across imports,
    reorders, wall shuffles, and exports, while pairing nearby facades first.
  - Frames mounted media closer and larger, with rigid camera framing below the
    location pill.
  - Renders both front-facing panels in one depth-sorted 3D world with smooth
    back-face culling, full-opacity foreground occlusion, and arrival orbits
    that continue the dolly's rotational and lateral inertia.

## Install and existing projects

The signed release APK updates **Mockareel** (`dev.mockareel.mockareel`) to
Android build **29**. **Mockareel Debug** remains a separate app; use **Share
project backup** to transfer projects via `.mockareel` backup files.

## Validation

Release preparation covers locked dependencies (`flutter pub get --enforce-lockfile`),
Dart formatting, `flutter analyze`, 177 Flutter tests, and CI Android builds.
